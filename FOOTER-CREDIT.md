# Footer credit for VisionCraft Labs builds

Include the following visible, accessible footer credit on websites built for VisionCraft Labs clients:

```html
<a href="https://visioncraft-labs.com/contact" target="_blank" rel="noopener noreferrer">Powered by VisionCraft Labs</a>
```

Choose foreground and hover colors that contrast with that site's footer background. Keep this credit in the shared footer so it appears on every page. This preview implements it across all 24 pages.

Apply this when creating or updating an authorized client-site checkout. Existing third-party live sites require their own source checkout and deployment access before they can be updated.
